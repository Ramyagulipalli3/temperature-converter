# Temperature Converter Website

This project is a simple Temperature Converter Website created using HTML, CSS, and JavaScript.

## About The Project

The Temperature Converter Website allows users to convert temperature values between Celsius and Fahrenheit easily.

## Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Simple and user-friendly interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How To Use

1. Enter temperature value
2. Select conversion type
3. Click on Convert button
4. View the converted result
